Who holds the repositories

These are decentralised identifiers, truncated to fit. The node resolves names for peers and for itself, not for repository owners, so there is no human name to show here and inventing one would be a lie.

What they keep building

Repository names grouped by stripping one trailing instance marker, so my-project, my-project2 and my-project-1785947444 count as one idea. It is a rule about names and nothing else: it cannot tell two unrelated repos apart if they picked the same name, and it does not look inside a single one of them.

When the work happens

Every repository creation placed on a UTC weekday and hour. Rows are days, columns are hours, and the size and brightness of each square is how many repositories appeared in that slot across the whole five months.

How long an owner stays

For every owner, the first and the last day on which they created a repository, and the gap between the two. A gap of zero means everything they own appeared on one day.
